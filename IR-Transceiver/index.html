    How to use

    Getting started

    1. Power the NPG board and press Connect. Pick NPG-IR from the browser dialog.
    2. Hold the user button for 1.5 seconds and let go. The app shows a listening overlay.
    3. Point a remote at the board and press a key. The capture dialog opens here. Type a name and save it.
    4. Short press the user button to fire the active command, or use the Fire button.

    The user button

    Short press
    Fires the active command
    Hold 1.5s
    Starts recording, then you can let go
    While recording
    A short press cancels it

    Recording stays on after you release the button. It ends when a signal arrives, after 15 seconds, or when you cancel. If a capture is still waiting to be named, starting a new recording replaces it.

    How it is stored

    Each command is split across two places on the board. Names and the active slot live in NVS. The captured waveform lives in LittleFS. A capture stays in RAM only until you name it, so a reboot before naming loses it.

    NVS
    20 KB, about 250 names
    LittleFS
    1 MB, about 250 signals
    This build
    50 commands, 16 characters each

    Both survive a firmware upload. Use Erase all below to clear them, or run a full chip erase from the command line. Flash the board with the Huge APP (3MB No OTA/1MB SPIFFS) partition scheme, otherwise the sketch barely fits.

    Requirements

    Web Bluetooth works in Chrome and Edge on desktop and Android. Firefox and Safari do not support it. On Android, Location must be on for Bluetooth scanning.

    Erase all

    Removes every saved name and waveform from the board. This cannot be undone.
